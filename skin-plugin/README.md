# SMPClassSkins 1.0.0

Дополнительный косметический плагин для Paper/Purpur 1.21.11 и Java 21. Работает рядом с основным SMPClasses и хранит коллекцию отдельно.

## Установка

1. Скопируйте \`SMPClassSkins-1.0.0.jar\` в \`plugins/\` рядом с основным SMPClasses и перезапустите сервер.
2. Установите ресурс-пак \`SMPClassSkins-ResourcePack-1.0.0.zip\` клиентам или разместите его на веб-хостинге и укажите ссылку в \`server.properties\` через \`resource-pack=\`.
3. Игрок использует \`/case\` для открытия кейса и \`/skin\` для выбора открытых скинов.

## Возможности

- Открытие кейса стоит 1 алмаз.
- В пуле 18 скинов разных редкостей; дубликат возвращает 2 алмаза.
- \`/skin\` открывает категории: мечи, топоры, кирки, лопаты, мотыги, луки, арбалеты, трезубцы, булавы, щиты и броня.
- Выбранный скин применяется к предметам соответствующей категории в инвентаре и броне игрока.
- Применение меняет внешний вид, но не урон, прочность, зачарования или другие характеристики.
- Коллекция и активные скины сохраняются в \`plugins/SMPClassSkins/skins.yml\`.
- Ресурс-пак включает 2D-текстуры, voxel-style 3D-модели, стадии натяжения лука и текстуры носимой брони для Java 1.21.11.

## Сборка

\`mvn -f skin-plugin/pom.xml clean package\`

Ресурс-пак генерируется стандартной библиотекой Python:

\`python3 skin-plugin/resourcepack/build_pack.py target/SMPClassSkins-ResourcePack\`
