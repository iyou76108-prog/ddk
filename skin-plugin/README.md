# SMPClassSkins 1.1.0

Дополнительный косметический плагин для Paper/Purpur 1.21.11 и Java 21. Работает рядом с основным SMPClasses и хранит коллекцию отдельно.

## Установка

1. Скопируйте `SMPClassSkins-1.1.0.jar` в `plugins/` рядом с основным SMPClasses и перезапустите сервер.
2. Оставьте включённым ресурс-пак SMPClassSkins (или объединённый архив с ним).
3. Игрок использует `/case` для открытия кейса и `/skin` для выбора открытых скинов.

## Команды игроков

- `/case` — открыть кейс за 1 ключ, алмазы не требуются.
- `/skin` — открыть коллекцию и надеть скин.

## Команды администратора

Требуется permission `smpclassskins.admin` (по умолчанию OP).

- `/skinadmin [ник]` — открыть админ-панель со всеми 18 скинами и выдавать выбранный скин указанному игроку. Без ника открывается выдача самому себе.
- `/key <ник> [количество]` — выдать игроку от 1 до 64 ключей кейса. Команду можно выполнять из консоли.

Ключ — специальный предмет с защищённой меткой. Обычный крюк/предмет не засчитывается как ключ. На дубликат выпавшего скина возвращается один ключ.

## Скины и хранение

- В пуле 18 скинов разных редкостей.
- `/skin` открывает категории: мечи, топоры, кирки, лопаты, мотыги, луки, арбалеты, трезубцы, булавы, щиты и броня.
- Выбранный скин применяется к предметам соответствующей категории в инвентаре и броне игрока.
- Применение меняет внешний вид, но не урон, прочность, зачарования или другие характеристики.
- Коллекция и активные скины сохраняются в `plugins/SMPClassSkins/skins.yml`.
- Ключи, не потраченные при отключении игрока в процессе открытия, возвращаются при следующем входе.

## Сборка

`mvn -f skin-plugin/pom.xml clean package`

Ресурс-пак не изменился и совместим с версией плагина 1.1.0.
