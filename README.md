# SMP Classes — Purpur 1.21.11

Плагин добавляет пять RPG-классов на анархичный SMP-сервер Minecraft.

## Сборка и установка

Требуется Java 21 и Purpur 1.21.11 (Paper API 1.21.11).

Локальная сборка:
```bash
mvn clean package
```

Готовый файл:
`target/SMPClasses-1.0.0.jar`

Скопируйте JAR в папку `plugins/` сервера и перезапустите сервер. Плагин создаст `plugins/SMPClasses/config.yml` и `plugins/SMPClasses/data.yml`.

GitHub Actions автоматически собирает проект при каждом push в `main`. JAR публикуется как artifact соответствующего запуска workflow **Build plugin**.

## Управление

При первом входе игроку показывается меню выбора класса. Выбор сохраняется по UUID и переживает выход, смерть и перезапуск сервера.

- **F** — переключить первые 9 слотов хотбара между обычным инвентарём и панелью способностей.
- Выбрать слот 1–5 и нажать **ПКМ** — применить способность.
- **ЛКМ** не применяет способность.
- Повторное нажатие F возвращает сохранённый хотбар. Переключение панели не имеет кулдауна.
- Кулдауны способностей сохраняются в `data.yml`.

Команды:
- `/class` — показать свой класс и подсказку.
- `/classadmin set <игрок> <класс>` — назначить класс игроку.
- `/classadmin reset <игрок>` — сбросить класс и открыть меню выбора.
- `/classadmin reload` — перечитать конфиг.

Допустимые идентификаторы классов: `druid`, `duelist`, `summoner`, `slave_owner`, `chameleon`. Для админ-команд нужна permission `smpclasses.admin` (по умолчанию OP).

## Классы

### Друид
1. **Корни земли** — замедляет цель и не даёт прыгать 2,5 секунды.
2. **Порыв чащи** — рывок вперёд до 9 блоков.
3. **Шипастая лоза** — снежок-снаряд, 3 сердца урона и отравление.
4. **Кора древних** — сопротивление и поглощение.
5. **Сердце рощи** — лечит игроков в радиусе 8 блоков и снимает яд/иссушение.

### Дуэлянт
1. **Идеальное парирование** — на 2 секунды уменьшает первый входящий удар и контратакует.
2. **Быстрый выпад** — рывок к цели и урон при сближении.
3. **Вызов на дуэль** — помечает игрока на 8 секунд; урон по нему увеличен на 25%.
4. **Вихрь клинков** — круговая атака в радиусе 4 блоков.
5. **Последний раунд** — сила, скорость и сопротивление на короткое время.

### Призыватель
1. **Спутник души** — духовный волк на 35 секунд.
2. **Костяной дозор** — два скелета-лучника на 25 секунд.
3. **Цепи могилы** — замедление и слабость в области.
4. **Перекличка душ** — возвращает прислужников и немного лечит владельца.
5. **Древний страж** — железный голем на 15 секунд.

Одновременно действует лимит 5 обычных прислужников.

### Рабовладелец
1. **Моё место** — поставить флаг и создать деревню из двух жителей. Повторное использование убирает флаг и прячет жителей; следующая установка возвращает их. Дать жителю 20 хлеба или моркови ПКМ — добавить жителя, максимум 8 жителей деревни.
2. **Работайте за меня** — открыть меню приказов и выбрать роль. После выбора нажмите ПКМ по своему жителю, чтобы назначить ему профессию. ПКМ по своему жителю без выбранной роли открывает его склад.
3. **Армия** — 15 вооружённых жителей на 23 секунды. ПКМ по врагу задаёт цель всей армии; Shift распускает её. Экипировка выпадает при убийстве бойца.
4. **Мега житель** — три жителя образуют башню, игрок едет сверху 15 секунд.
5. **Возьму взамен** — пассивно +2 сердца и +0,5 брони за каждого принадлежащего владельцу жителя.

Назначаемые роли: мечник, лучник, шахтёр, дровосек, фермер. Чтобы выдать снаряжение, откройте склад жителя: первый слот — основной инструмент/оружие, второй — стрелы для лучника. При закрытии склада экипировка переносится на жителя. Без нужного инструмента эффективность работы снижается в 15 раз.

Сейчас сбор ресурсов реализован как локальная работа рядом с жителем (поиск блоков в радиусе 5 блоков); житель должен находиться не дальше 180 блоков от флага. Обрабатываются загруженные чанки. Для фермеров собираются и заново сажаются зрелые культуры; шахтёры добывают руду; дровосеки рубят отдельные брёвна. Работа не отправляет жителя автоматически путешествовать по всем 180 блокам.

Скрытая внутренняя механика выбора профессии не отображается отдельным слотом. Пассивка **«Возьму взамен»** отображается, как и указано в описании класса.

### Хамелеон
1. **Мой окрас** — невидимость на 4 секунды и скорость II.
2. **Свой среди чужих** — пассивно: враждебные мобы не выбирают игрока целью; их прямой урон по хамелеону отменяется.
3. **Лизнуть языком** — снежок цепляется за блок/сущность и подтягивает игрока со скоростью около 2 блоков в секунду; максимальная дальность 33 блока.
4. **Живучесть** — пассивно +0,5 максимального здоровья за каждый блок листвы в кубе 7×7×7 вокруг игрока.
5. **Копирование** — копирует случайную активную способность игрока в прицеле на 80 секунд; кулдаун 2 минуты. Повторный ПКМ по пятому слоту применяет скопированную способность.

## Настройки

Все кулдауны, длительности и лимиты находятся в `src/main/resources/config.yml`; после первого запуска файл копируется в папку плагина.

## Данные и технические детали

- Класс, кулдауны, сохранённая панель хотбара, флаг и склады жителей хранятся в `data.yml`.
- UUID владельца и тип временного существа хранятся через PersistentDataContainer.
- Временные прислужники, армия и Мега житель удаляются при окончании действия; оставшиеся временные существа очищаются после перезапуска.
- Сущности и блоки обрабатываются на основном потоке сервера.
- Плагин не требует клиентских модов или ресурс-пака.

Это первая рабочая реализация. Её нужно протестировать на копии вашего реального сервера, особенно взаимодействие нескольких владельцев, PvP, выгрузку чанков и баланс дополнительных сердец/брони.
